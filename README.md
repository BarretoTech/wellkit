# wellkit

This repository only hosts release assets for the `wellkit` npm package: compiled binaries and a SHA-256 manifest. No source code lives here.

## Install

```sh
npm i -g wellkit
# or
npx wellkit
```

On first run the npm package downloads the binary for your platform from this repository's releases and verifies it against checksums embedded in the npm package.
